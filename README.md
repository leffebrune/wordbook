# Wordbook

9세 아이가 영어 단어 옆에 한국어 뜻을 쓰고 한 번에 채점받는 개인용 PWA. 부모는 구글 시트에서 단어와 모델을 관리한다. 앱은 시트와 OpenRouter를 휴대폰에서 직접 호출한다. PC는 최초 설치·재설치·업데이트에만 필요하다.

## 1. 시트 만들기

`words` 탭에 아래 셀을 채운다.

| 셀 | 값 |
| --- | --- |
| A1 | `word` |
| B1 | `focus` |
| D1 | `model` |
| E1 | 구조화 출력을 지원하는 OpenRouter 모델 ID, 예: `openai/…` |
| A2 이후 | `take`, `get` 등 단어 |
| B2 이후 | 선택 설명: `가방을 학교에 가져가는 장면` |

시트 공유 설정을 **링크가 있는 모든 사용자: 뷰어**로 한다. `words` 탭의 `gid`는 브라우저에서 해당 탭을 열었을 때 주소의 `gid=...` 숫자다. 시트 ID는 주소의 `/d/`와 `/edit` 사이 문자열이다. Google Visualization CSV 주소 `https://docs.google.com/spreadsheets/d/<ID>/gviz/tq?gid=<GID>&tqx=out:csv&headers=0`를 로그인하지 않은 브라우저에서 열어 읽히는지 확인한다. 이 탭에는 단어와 학습용 메모만 넣는다.

## 2. 로컬 설정과 실행

Node.js가 필요하다. `src/config.local.example.ts`를 `src/config.local.ts`로 복사하고 `sheetId`, `sheetGid`, `openRouterApiKey`에 실제 값을 하드코딩한다. 이 파일은 Git에서 제외된다. 시트 E1의 모델은 앱을 다시 빌드하지 않고 바꿀 수 있다. 구글 응답에 반영된 뒤 다음 채점부터 사용된다.

```bash
npm install
npm test
npm run build
npm run preview
```

`npm run dev`는 개발용이다. 설정 파일이 없더라도 화면은 빌드되며 설정 안내가 표시된다. **실제 키를 넣어 빌드한 JavaScript에는 키가 포함된다.** 설치된 휴대폰에서도 추출할 수 있으므로 앱 전용 OpenRouter 키에 낮은 사용액 한도를 걸고 공개 저장소에 빌드 산출물을 올리지 않는다. `dist/`와 실제 설정 파일은 Git에서 제외한다.

## 3. 휴대폰에 설치

PC와 휴대폰이 같은 집 공유기에 연결되어 있어야 한다. PC의 LAN IP를 공유기에서 예약한다. PWA 설치와 서비스 워커에는 **휴대폰이 신뢰하는 HTTPS 출처**가 필요하다. 일반 `http://192.168.x.x`나 인증서 경고를 무시한 접속은 설치 검증 경로가 아니다.

로컬 인증서 도구(예: mkcert)로 **PC LAN IP가 SAN에 포함된** 인증서를 만들고 다음 위치에 둔다. 인증서 발급자의 루트 인증서를 휴대폰에 설치해 브라우저가 이 주소를 신뢰하도록 한다. 개인키는 PC 밖으로 공유하지 않는다. 앱은 두 파일이 모두 있으면 Vite preview를 HTTPS로 실행한다.

```text
certs/lan.crt
certs/lan.key
```

빌드 후 `npm run preview -- --port 4173`을 실행하고 휴대폰에서 `https://<PC의 LAN IP>:4173`을 연다. Chrome 또는 Samsung Internet에서 설치를 진행한다. 첫 페이지 로딩 후 서비스 워커가 활성화되고 정적 파일이 저장될 때까지 기다린다. **PC를 끄거나 네트워크를 차단한 뒤 홈 화면 아이콘으로 재실행해** 앱이 열리고 휴대폰 데이터망에서 시트 로드와 채점이 되는지 확인한다. 브라우저가 사용자 설치 루트 인증서를 PWA용으로 신뢰하지 않으면, 정식으로 신뢰되는 HTTPS 주소를 마련해 같은 절차로 검증해야 한다.

설치 후 앱 코드는 PC API에 요청하지 않는다. 다만 브라우저 자체의 서비스 워커 업데이트 확인은 설치 원본 주소를 조회할 수 있다. 앱 셸 캐시가 휴대폰에서 지워지면 PC 없이 실행을 보장할 수 없고, 업데이트·재설치에도 PC가 필요하다. 시트와 OpenRouter에 연결하려면 휴대폰 인터넷은 계속 필요하다.

## 오류 확인

- `시트 ID와 gid`: 설정 파일의 값 확인.
- `A1=word…`: 시트 첫 행과 `words` 탭 gid 확인.
- `단어를 불러오려면 인터넷이 필요해요`: 시트 공유 범위, 주소, 휴대폰 인터넷, 브라우저 CORS 확인.
- `모델 설정`: E1에 정확한 OpenRouter 모델 ID 확인.
- `채점 모델을 사용할 수 없어요`: OpenRouter 키·잔액·모델의 구조화 출력 지원 확인.

첫 검증은 실제 휴대폰에서 시트 CSV GET과 OpenRouter POST가 **서버 프록시 없이** 동작하는지 확인하는 것이다. 두 서비스의 브라우저 CORS 정책이 바뀌면 앱 코드만으로 우회할 수 없다.
